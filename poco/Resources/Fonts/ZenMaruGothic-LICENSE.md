# Zen Maru Gothic

Pocoの日本語・欧文表示には、Zen Maru Gothicを使用します。

- Source: https://github.com/googlefonts/zen-marugothic
- Distribution: https://github.com/google/fonts/tree/main/ofl/zenmarugothic
- Copyright: Copyright 2021 The Zen Maru Gothic Project Authors
- License: SIL Open Font License, Version 1.1

同梱しているのはRegular、Medium、Boldの3ウェイトです。ライセンス全文は
`OFL-ZenMaruGothic.txt`を参照してください。

フォントが読み込めない場合は`PocoTypography`がiOSのシステムフォントへ
フォールバックします。
