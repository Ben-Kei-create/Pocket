# Legacy animal assets

Pocoで以前使用していた動物画像の退避先です。Asset Catalogから外しているため、アプリには同梱されません。

- `LegacyProfileAvatars`: 旧プロフィール画像5種
- `LegacyCompanions`: 旧ぷよ画像5種
- `LegacyRareCompanions`: 旧Proレアキャラクター8種

復元する場合は、対象の`.imageset`を`poco/Assets.xcassets`へ戻し、`BuiltInAvatar`または`RareCompanionKind`の画像マッピングを更新してください。
